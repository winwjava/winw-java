# 实时三维环境感知场景

目标是黑底参考网格、真实透视、可旋转的实体/表面场景。新原生 Swing 视图由 CPU 绘制，不要求 GPU、浏览器 CDN 或用户标定文件。

## 实时相机

```powershell
.\docs\slam\run-scene.ps1 -Mode camera -InputSource 0 -BaselineMm 65
```

也可直接运行 `StereoSlamDemo.main`（无参数），打开相机后默认进入“三维环境（实时）”页，原来的左右图/视差保留在调试页。默认使用用户提供的本设备基线65mm；设置模型本身仍允许0表示未填写。

CPU流水线：双目采集 → 自然场景纵向对齐 → SGBM → 有效区域/深度置信度过滤 → 相机局部OCC → 半格等值面重建 → 灰色连续三角面片 → 透视绘制。全局定位丢失不阻止有深度证据的局部几何显示。无效深度、未对齐图像和零基线不产生实体，遮挡后未知区域不补全。

左键拖动旋转，右键或Shift拖动平移，滚轮缩放。“适应三维场景”恢复取景。参考网格放在观测包围范围下方，未估计真实地面。场景采用相机局部坐标，不表示已经完成全局SLAM。

## 实拍序列回放

已生成的120帧OCC无需再次采集：

```powershell
.\docs\slam\run-scene.ps1 -Mode replay -InputSource .\target\occ-3d
```

窗口显示三维场景与对应原图，可播放、拖动帧滑块及旋转视角。保存的真实图片效果在 `target/occ-3d/scene-preview.png`。离线导出时加 `-Headless`，不会打开窗口。

## 当前边界

这是环境几何感知与场景渲染，还不是参考图的完整对象级语义感知。当前没有车辆、行人等类别识别、三维实例跟踪、姿态估计或按类别选取模型，因此不会凭空插入车辆/人物模型。参考图中的规则汽车外形不能由OCC换皮获得。

目前相机几何仍使用图宽焦距先验与投影对齐，米制精度未验证；弱纹理、反光、遮挡和动态物体仍会造成噪声和缺口。表面插值只在相邻已观测占据单元的半格范围内构造显示边界，不代表预测了未知物体内部或背面。

本轮用实际录制数据生成了三维预览，并通过原生面板无界面渲染测试；没有在实体摄像头上验证端到端实时FPS。界面会显示采集线程中的深度/OCC处理耗时，该数值不含EDT表面重建和绘制耗时，不可当作完整FPS。
