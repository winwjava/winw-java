# 三维 OCC 图片回放

直接运行（CPU，不需要显卡、模型下载或用户标定文件）：

```powershell
.\docs\slam\run-occ.ps1 -Sequence .\target\auto-b96cc826-19e0-4abe-b73d-5080c5495d18 -BaselineMm 65
```

输出 `target/occ-3d/index.html`，双击用浏览器打开。所有数据和缩略图都内嵌，可离线旋转、缩放、切换120帧、播放，并查看第23帧的历史融合快照。采用 Canvas 软件绘制体素六面，没有将点云渲染冒充体素。原图颜色来自体素中心投影，没有语义分类。

后端：SGBM 深度观测 → 5cm 占据栅格 → DDA 射线更新 → 带置信度的概率融合。遮挡后和没有深度证据的空间保持 UNKNOWN。单帧局部视图允许一次命中生成占据，不代表时序确认；单次空闲证据可能不足以通过 FREE 阈值。完整概率、命中/空闲次数及状态保存在 `volumes/frame-XXX.csv`。

本次120帧都有非空局部占据，30帧通过位姿检查进入全局融合。局部占据不等于定位成功。最丰富的历史融合快照在第23帧，1983个占据体素、2584个空闲体素，保存在 `global-best-occupancy.csv`。它不是结束时刻的地图；全局失去跟踪后不会把局部相机坐标强行当成世界坐标继续融合。

图像宽度焦距先验、纵向投影对齐和已知65mm基线仍是近似几何，名义米制精度未验证。现有结果有缺口、噪声和动态人物残留。这是可检查的几何 OCC 原型，不包含特斯拉的语义/时序神经网络及训练数据，也不预测遮挡后的物体体积。

`OccupancyReplay` 不输出 PLY。查看器显示占据体素，空白可能是 FREE 或 UNKNOWN，不能一概当作可通行。全部三态信息以 CSV 保存。界面最多显示每帧7000个占据体素、融合14000个；CSV不按此显示上限抽样。

验证：60项SLAM/OCC测试通过。新增集成测试验证空白图片不生成占据、LOST状态保留且不伪造PLY输出。浏览器实测拖动旋转、切换119帧、融合模式和360px布局，无脚本错误。
